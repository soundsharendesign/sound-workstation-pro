SOUNDWORKSTATION

📖 SOUNDWORKSTATION 总使用教程

这是一个用于音色设计、编曲、和弦、节奏和课堂演示的多轨声音工作站。第一次使用时，建议先点击“播放”，确认四条轨道都能同时发声，再开始修改。

① 先认识四条轨道

轨1 旋律：负责主旋律，可以输入简谱数字 1～7。
轨2 和弦：负责和声，可以写 I～vii° 对应的级数。
轨3 贝斯：负责低音，可以输入 1～7。
轨4 鼓组：使用 K Kick、S Snare、CH Closed Hat、OH Open Hat、C Clap、T Tom、R Crash。

② 最简单的 DAW 用法

先确认右侧显示“使用 DAW 多轨”，然后点击 ▶ 播放。BPM 可以实时调整；“循环”打开后会不断循环。四条轨道的 Vol 可以单独控制。

默认自带一段示范曲：轨2 是 1 - - - | 5 - - - | 6 - - - | 4 - - -（C–G–Am–F），轨3 走根音—五音 1 - 5 - | 5 - 2 - | 6 - 3 - | 4 - 1 -，轨4 是 K S K S（底鼓 1/3 + 军鼓 2/4），轨1 是旋律。改乱了点 🎵 示范曲 就能恢复。也可以自己写：1 2 3 5 | 6 5 3 2（轨1）+ 1 1 5 5 | 6 6 3 3（轨3）+ K S K S | K S CH S（轨4）。

③ 简谱里的常用写法

1 2 3 = 连续四分音符；[1 2] = 两个八分音符；[[1 2 3 4]] = 四个十六分音符；{1 2 3} = 三连音；1. = 附点（时值 ×1.5）；1' = 高八度；1, = 低八度；- = 延长/空拍；| = 小节分隔。轨2和弦还可以在控制条里选择“琶音”，写 1 - 5 - 就会自动展开成琶音。

④ 播放中也可以直接改谱

工作站支持播放中实时修改音符。直接修改轨1～轨4输入框，尚未播放的后续内容会采用最新设置，不需要先停止。

⑤ 音色设计：先选轨道，再调音色

在“独立通道条”里先选择 轨1 / 轨2 / 轨3 / 轨4，再设置这个轨道的音色。每条轨道都有独立的 OSC、Filter、ADSR、EQ、Drive、Chorus、Delay、Reverb 和 Pan。

常用思路：旋律可以提高 Cutoff 和一点 High；贝斯可以降低 Cutoff、增加 Low；和弦可以加入 Chorus / Reverb；鼓组一般保持快速 Attack 和较短 Release。

⑥ 和弦区怎么用

先选择当前调性，例如 C 大调。下面的 I、ii、iii、IV、V、vi、vii° 就是该调的七个自然级和弦。每张卡片都可以选择不同的和弦结构。

例如 C 大调的 V 级是 G：选择 7 就会得到 G-B-D-F；选择 9 会加入 A。选择 Maj7 / Maj9 / m7 / m9 / dim7 等时，实际播放的音程也会随选择改变。

⑦ 琶音怎么用

和弦区的“和弦播放方式”可选：柱式、琶音·上行、琶音·下行、琶音·上下往返、琶音·随机。按住任意和弦卡片即可试听，松开后停止。

快慢有两级控制：琶音速度决定每个音的时值（64分 / 32分 / 16分 / 8分 / 4分），快慢滑杆在这个时值上整体加速或减速（0.25× 更慢 ～ 4× 更快）。

DAW 轨2（和弦）也可以单独设置琶音：在“DAW 多轨音序器”的控制条里选择 轨2和弦 的发声方式与琶音时值，写入 1 - 5 - | 6 - 3 - 这样的和弦级数后播放，就会自动展开成琶音。

⑧ 自定义和弦

选择某张和弦卡片的 自定义，输入和弦名称和音程。音程使用“相对于根音的半音数”，例如：

0,4,7 = 大三和弦；0,3,7 = 小三和弦；0,4,7,10 = 属七；0,4,7,11 = 大七；0,4,7,10,14 = 属九；0,4,7,10,15 = 7♯9。

自定义和弦会跟随当前 Key 移调，所以换调后仍然保持相同的和弦结构。

⑨ Step Sequencer 怎么用

点击“使用 Step Sequencer”后，每一格代表一个起音位置。轨1 / 轨3 可以直接选择音高；轨2 和轨5 Pad 都选择和弦级数（Pad 会自动拉成长音垫底）；轨4 连续点击可以循环切换鼓点。顶部可以选择四分、八分、十六分或三连音网格。写好轨2的和弦进行之后，用下方的「🌫 复制轨2 → 轨5 Pad」可以一键把同样的级数铺到 Pad 轨上去。

⑩ 键盘与课堂演示

最下面的键盘可以直接点击演奏。当前选择的轨道决定键盘使用哪一个音色。可以开关唱名、音名，也可以切换显示八度。和弦卡片被按住时，对应音高会在键盘上实时显示。

⑪ 节拍器

打开“独立节拍器”，选择拍号，例如 4/4、3/4、6/8。节拍器 BPM 与工作站 BPM 同步，适合课堂上讲节拍、速度和切分。

⑫ Solo / Mute

DAW 与 Step 里每条轨道都有 S（Solo） 和 M（Mute） 两个小按钮：Solo = 只播放这一轨，其他轨道静音；Mute = 静音这一轨，其他轨道不变。可以同时 Solo 多条轨道；只要有任意一条处于 Solo，其余轨道就都不发声。导出 WAV 时也会沿用这个设置。

⑬ 实时编曲视图 / 音色曲线

DAW 四条轨道的正下方就是实时编曲视图：横轴是时间（每 4 拍一条粗线并标小节号），纵轴是音高，底部是鼓组的 7 条鼓件轨；播放时绿色竖线会跟着走，正在发声的音变白高亮。右上角的四个轨道名可以单独隐藏某一轨的图形。

通道条里，ADSR 参数下面就是 ADSR 包络曲线（黄线 = 延音电平 S，红色区 = 释音 R），EQ / Drive 参数下面就是 EQ 频响曲线；拖动滑杆时曲线同步变化，点 ▶ 试听包络 可以立刻听到当前 A / D / S / R 的差别。S = 按住时保持的音量，R = 松键后尾音拖多久（不再被音符时值吃掉）。

⑭ 乐理课堂（点开才展开）

和弦区的 📘 乐理课堂 按钮，点一下才展开教学模块（再点一次收起）。七个标签按从零件到整体的顺序排列：① 音程（半音数 / 名称 / 协和度 + 音程转位三条规律）、② 音阶与调式（当前音阶、调内七级数、七种调式对比，可一键切换全站调式）、③ 和弦怎么搭出来（三度叠置，可现场拼和弦）、④ 常用和弦的区别（十种和弦逐个试听）、⑤ 和弦转位（原位 / 第一 / 第二转位、分数和弦 C/E、低音级进示例）、⑥ 主 · 下属 · 属（T / S / D）（功能和声与四种终止式）、⑦ 和弦连接与进行（声部进行规矩 + 常见进行可写入 DAW 轨2）。所有例子都跟着当前的主音 + 调式自动移调。

⑮ 调式 / 音阶

和弦区除了选主音（C、D、E…），还能选调式：大调、自然小调、和声小调、旋律小调、五声音阶（宫 / 羽）、Blues 音阶。切换后七个级数的名称与性质会整体改变（大调是 I–ii–iii–IV–V–vi–vii°，自然小调是 i–ii°–III–iv–v–VI–VII），和弦卡片、Step 轨2、乐理课堂的例子全部跟着变。五声音阶与 Blues 本身凑不出七个三和弦，所以和弦沿用母调的级数。

⑯ Swing / Shuffle 摇摆

DAW 控制条里的 Swing 开关 + 摇摆量滑杆，把每一拍的后半拍往后推，做出摇摆感（0% = 完全平均，100% = 三连音摇摆）。DAW 与 Step 同时生效，播放中拖动会立刻跟着变，播放头也会跟着一起摆。

⑰ 撤销 / 重做

屏幕右下角悬浮着 ↶ 撤销 / ↷ 重做两个大按钮（手机也好点），DAW 与 Step 的工具条里也各有一组。任何一步操作——改谱面、点 Step 格子、调参数、切换调式、清空轨道——都会记一步，点一下就回到上一步的状态，最多 60 步。电脑上也可以用 Ctrl / ⌘ + Z 撤销、Ctrl / ⌘ + Shift + Z 重做（在输入框里打字时仍然是浏览器自带的文本撤销）。

⑮ Step 的延音与清空

Step Sequencer 里，轨1 / 轨2 / 轨3 每个子拍右边都有一个 ⏜ 延音 按钮：点开后这一格不再重新起音，而是把前一个音的时值往后延长（相当于简谱的延音线），用来写长音和切分。轨4 鼓组的每个芯片右边有 ✕ 可以一键清空，在芯片上点右键也可以直接清空。轨5 Pad 与轨1 / 轨2 一样也有 ⏜ 延音，适合做跨越整小节的长音铺底。

⑱ 卡片式工作区（点哪张卡显示哪一块）

在节拍器下面有一排四张选择卡：① Step Sequencer · ② DAW 多轨 · ③ 音色设置 · ④ 智能和弦系统。点哪一张就只显示那一块，页面更短、手机上也不用一直滚。键盘区、走带控制、节拍器、工程栏永远都在，不会被切走。手机上这四张卡会自动变成屏幕下方的固定标签栏，随时可以换。上次停在哪一张会被记住，下次打开还是它。

⑲ 轨5 Pad：一层铺在下面的氛围

Pad 是「垫底」的音色，负责把整段音乐黏成一片。DAW 里它的写法和轨2完全一样，填 1～7 的和弦级数就行，系统会自动把每个音拖到至少一拍长。Step 里轨5也是选和弦级数，写好轨2之后点「🌫 复制轨2 → 轨5 Pad」可以一键铺上去。

音色在「音色设置」里选到 轨5 [Pad]，会多出一块 「轨5 PAD 氛围塑形」：叠加层数（几层同时响）、失谐宽度（层与层错开多少音分，产生缓慢拍频）、高频微光（加一层空气感）、亚低音（低八度托底）、渐入 Swell（把起音拉长成淡入）、音色漂移（每层缓慢随机游走）。配合底部的长 Release 与大混响就是标准的 Pad。四种 Pad 音色在音源下拉框最后一组：温暖 / 玻璃 / 人声 / 弦乐。

⑳ LFO：让音色一直“动”

LFO 是一条很慢的振荡器，周期性地推动你指定的参数。调制目标四种：滤波 Cutoff（最常用，持续的扫频呼吸感）、音量（起伏抖动）、音高（颤音 Vibrato）、声像（左右飘移）。速率小于 1Hz 是缓慢呼吸，2～6Hz 是明显颤动，大于 8Hz 变成金属感的抖动。深度是推动幅度，淡入延迟让它在音符响一会儿之后才慢慢加入，同步可以把一圈锁在 1 / 2 / 4 拍上跟着 BPM 走。波形有正弦 / 三角 / 方波 / 锯齿 / 随机五种，下方小图实时画出形状。轨5 Pad 默认就挂着一条 0.35Hz 的慢滤波扫动，所以即使什么都没调，它听起来也是活的。
